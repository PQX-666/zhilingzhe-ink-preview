## 卡 1-A｜五型识别卡（观察用）

**进门三分钟，扫这 12 项，勾中 3 项以上先假设是这一型。**

| 观察维度 | 老虎 | 孔雀 | 考拉 | 猫头鹰 |
|---|---|---|---|---|
| 说话速度 | 快、短句 | 快、话多 | 慢、有停顿 | 慢、精准 |
| 用词习惯 | "说重点""直接说" | "超好玩""我跟你讲" | "都行""你们定" | "具体是""有依据吗" |
| 关注点 | 结果、效率 | 人、气氛 | 关系、稳定 | 细节、逻辑 |
| 坐姿 | 前倾或后靠，占空间 | 动作多，手势大 | 收敛，靠椅背 | 端正，手交叉 |
| 被夸时 | 无所谓 | 明显开心，接着讲 | 不好意思，转移话题 | 质疑夸奖的依据 |
| 被打断时 | 打断回来 | 提高音量 | 让步，不说了 | 沉默，记下来 |
| 做决定 | 快 | 快，事后会变 | 慢，需要人陪 | 慢，要回去核对 |
| 对寒暄 | 敷衍，想进正题 | 积极参与 | 配合但不主动 | 礼貌回应，等你说正事 |
| 填表时 | 3 分钟填完 | 边填边说话 | 慢慢来，会问"这题什么意思" | 反复回头看前面的题 |
| 填完第一句话 | "算出来是什么" | "这个准吗" | （不说话，等你） | "这个测评原理是什么" |
| 手机/穿搭 | 简洁、黑白灰 | 有个人风格 | 实用、不显眼 | 统一、有秩序 |
| 口头禅 | "然后呢" | "你知道吗" | "我都可以" | "得看情况" |

**变色龙判据（不看行为看分数）**：五组分数最高与最低相差小于 2 分，且没有一组明显突出。

**注意**：先看情境，再看类型。类型只决定"怎么说"，情境决定"要不要说"。

## 卡 1-B｜五型应对卡（沟通用）

| | 老虎 | 孔雀 | 考拉 | 猫头鹰 | 变色龙 |
|---|---|---|---|---|---|
| **破冰首句** | "等会儿还有事吗？我们三十分钟搞定" | 具体地夸他某个说法 | "先坐，不着急，今天没有考试" | "先说下流程和时间" | "你的结果跟大多数人不一太样" |
| **核心恐惧** | 失控、落后 | 被忽视、无聊 | 做错决定、起冲突 | 被骗、不确定 | 被贴标签、随波逐流 |
| **痛点入口** | 机会被别人拿走了 | 讲了但别人没听懂 | 想做的事一直没开始 | 算频率：四年要上台几十次 | 没有明确的出发点 |
| **最容易反感** | 铺垫长、被推销 | 被冷落、被否定 | 被催、被逼决定 | 夸张宣传、情绪煽动 | 三个选项、被说没主见 |
| **成交方式** | 给决定权，别替他定 | 邀请，不当场逼 | 最小台阶 + 保底退路 | 给证据 + 允许验证 | 给建议，不给选项 |
| **一句话禁忌** | "今天不定就是不够果断" | "大家都报了" | "室友和父母不理解你" | "别想太多" | "你什么都能适应" |

**三条对所有类型都成立的铁律**
1. 前 20 分钟不提价格
2. 影响量化占满 5 分钟，别漏"资源层"
3. 对方说话时间要超过六成

## 卡 2｜十三节点速查卡

**主线**：许可 → 大学 → 目标 → 时间 → 能力 → 圈子 → 金钱 → 意愿 → 课程 → 财力 → 选择 → 顾虑 → 结束

| 节点 | 要拿到什么 | 卡住了就问 |
|---|---|---|
| 许可 | 同意 + 知道可能涉及推荐 | "今天大概聊三十分钟，可以吗？" |
| 大学 | 对现状的真实评价 | "哪件事跟你高中想的最不一样？" |
| 目标 | 具体方向，或"没想清楚" | "这学期结束，你最想看到哪个变化？" |
| 时间 | 意识到时间稀缺 | "上周你的时间大概怎么分的？" |
| 能力 | 他自己说的短板 | "六项里，你最没底的是哪一项？" |
| 圈子 | 承认环境在影响他 | "你们寝室晚上在干嘛？" |
| 金钱 | 建立"投资"框架 | "你觉得大学生赚钱难在哪？" |
| 意愿 | 一个数字 + 一句理由 | "1-10 分打几分？为什么不是更低一分？" |
| 课程 | 需求与机制对齐 + 听到限制 | "你愿意听我用三分钟讲机制吗？" |
| 财力 | 资金来源与承受度 | "影响基本生活，还是不影响但要认真比较？" |
| 选择 | 他选出的方案 | "这三个里，哪个最接近你的目标？" |
| 顾虑 | 真实顾虑 | "如果课程本身匹配，你最后一个顾虑是什么？" |
| 结束 | 是 / 不是 / 暂缓 | "那你现在的决定是什么？" |

**三个不能因类型改变的问法**（横向可比）：意愿、财力、顾虑。

## 卡 3｜十三条顾虑应对卡

**五步**：听清 → 确认 → 分类 → 回应 → 回问

| 他说 | 先分清 | 关键回应 | 回问 |
|---|---|---|---|
| 太贵 | 现金不足 / 价值不清 / 压价 | 现金不足就降级，价值不清就补证据 | "你认为合理预算是多少？" |
| 我再想想 | 价格 / 价值 / 不好意思拒绝 | 给三种可能让他选 | "你希望想清楚哪三件事？" |
| 父母不同意 | 钱 / 安全 / 机构 / 时间 | 给书面资料，鼓励共同沟通 | "你希望我提供哪些事实？" |
| 没时间 | 冲突 / 机会成本 / 优先级低 | 列时间表与实习、专业课比较 | "如果课程免费，你还会因为时间拒绝吗？" |
| 怕被骗 | 主体 / 师资 / 合同 / 安全 | 给验证路径，不给保证 | "你会通过哪些渠道核实？" |
| 怕学不到 | 目标泛 / 教法不匹配 / 自己不练 | 定义可观察成果 | "学完两周后，哪个作品能证明？" |
| 怕坚持不了 | 经验 / 环境 / 目标不足 | 先做两周免费练习 | "什么安排让你过去坚持成功过？" |
| 专业更重要 | 很可能是真实优先级 | 承认专业是核心，必要时不推荐 | "专业任务之外还有多少稳定时间？" |
| 培训不是唯一 | 这是事实 | 比较六条路径，不贬低免费 | "你最愿意先试哪条？" |
| 不喜欢演讲 | 舞台 / 形式 / 无需求 | 无真实场景就不推荐 | "有没有必须表达的场景？" |
| 想先体验 | 理性降不确定性 | 明确观察清单 | "你准备用哪五个标准评估？" |
| 朋友不看好 | 事实 / 偏好 | 不贬低朋友 | "哪条意见最有证据？" |
| 没兴趣 | 明确拒绝 | **接受并结束** | "需要我不再发送课程信息吗？" |

**最危险的三句，提前背熟：**
- 太贵 → 不降价，先问"是拿不出，还是不确定值不值"
- 我再想想 → 不追问"想好了联系我"，要问"是哪一种"
- 怕被骗 → 不说"你放心"，要说"我给你三个可以查的东西"

## 卡 4｜现场决策树

```
对方愿意聊？ ──否→ 结束（"那我们不聊这个"）
   │是
拿到具体场景？ ──否→ 问"最近一次发生是什么时候"
   │是
影响量化做完五层？ ──否→ 补齐，别漏「资源层」
   │是
重要性 ≤5？ ──是→ 不推方案，转长期维护
   │否
讲了六条替代路径？ ──否→ 补讲，让对方选一条
   │是
对方主动问课程？ ──否→ "你想听听相关的训练方式吗？"
   │是
五项匹配评分（对方自评）
   ├ 0-3 → 不推荐付费
   ├ 4-5 → 体验或免费练习
   ├ 6-7 → 专项，或继续核实
   └ 8-10 ↓
财务四问通过？ ──否（需借贷/影响生活/需隐瞒）→ 停止
   │是
最后一个顾虑？ ──有→ 五步处理，回到本节点
   │无
确认决定
   ├ 是     → 讲合同和退费，进入流程
   ├ 需时间 → 约定回访 + 给资料 + 24 小时冷静期
   └ 不     → "收到，谢谢你直接说" → 两句话内结束
```

## 卡 5｜红线自检卡

**随时自问三句话**
1. 对方说的比我多吗？
2. 我有没有说过无法核验的话？
3. 这个决定是不是他自己做的？

**绝对不说的话**

| 类别 | 例子 |
|---|---|
| 承诺结果 | 保证就业、保证收入、保证变自信、保证不紧张 |
| 绝对化 | 百分百满意、全西南最好、一定、最 |
| 贴标签 | 你就是这种人、你这种人应该、你没有领导力 |
| 制造稀缺 | 今天不定就涨价（除非有书面依据，且不用于催单） |
| 从众压力 | 大家都报了、你不来会错过 |
| 离间关系 | 别听室友父母的、他们不理解你 |
| 资金风险 | 借钱也是成长、先交定金再说、生活费先垫上 |

**必须做到的四件事**
1. 报价前披露自己的收益关系
2. 提供免费或更低成本的替代路径
3. 高额支出给至少 24 小时冷静期
4. 对方拒绝后，两句话内结束且不再追

**出现以下任一情况，直接停止推进**
- 需要借贷、分期、透支生活费
- 需要隐瞒出资人
- 信息不完整且无法核验
- 对方表现出明显心理困扰（转介学校心理健康中心）
